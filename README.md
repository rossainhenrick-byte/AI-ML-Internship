# Titanic Survival Prediction – Data Analysis

## 📌 Project Overview

This project focuses on analyzing the Titanic dataset using Python and Pandas. The main objective is to understand the dataset, clean the data, perform exploratory data analysis, and identify factors that influenced passenger survival.

This project was completed as part of the **AI-ML Internship**.

## 🎯 Objectives

* Understand the Titanic dataset.
* Load and inspect the dataset using Pandas.
* Identify and handle missing values.
* Clean and preprocess the data.
* Perform basic exploratory data analysis.
* Analyze the relationship between passenger characteristics and survival.
* Create a cleaned dataset for further analysis.

## 📊 Dataset

The dataset contains information about Titanic passengers, including:

* Passenger survival status
* Passenger class
* Name
* Sex
* Age
* Number of siblings/spouses aboard
* Number of parents/children aboard
* Ticket information
* Fare
* Cabin
* Port of embarkation

The original dataset is stored as:

`Titanic-Dataset.csv`

The cleaned dataset is stored as:

`titanic_cleaned.csv`

## 🔍 Data Analysis Performed

The notebook includes:

1. Clone or download this repository.

3. Make sure `Titanic-Dataset.csv` is available in the same project folder.
4. Run the notebook cells from top to bottom.
