# Iris Flower Clustering Project

## Overview
This project contains the work completed for Assignment 1, Assignment 2, and Mini Project 3 using the Iris flower dataset.

## Tasks Completed

### Assignment 1: K-Means Clustering
- Applied the K-Means clustering algorithm to the Iris dataset.
- Grouped flower samples into three clusters.
- Visualized the resulting clusters.

### Assignment 2: Principal Component Analysis (PCA)
- Applied PCA for dimensionality reduction.
- Scaled the dataset before applying PCA.
- Visualized the reduced-dimensional data.

### Mini Project 3: Iris Flower Clustering
- Implemented K-Means clustering with three clusters.
- Compared predicted clusters with actual Iris species labels.
- Visualized clustering results and evaluated the clustering output.

## Dataset
The project uses `Iris.csv`, which contains measurements of Iris flowers.
